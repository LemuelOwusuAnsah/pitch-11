# Implementation Phases

## Phase 1 - Foundation - DONE
Astro + Phaser 3.90 + Matter scaffold, green pitch, deployed to Pages.

## Phase 2 - Ball + one player - DONE
Matter ball and player bodies, WASD/arrow movement, collision.

## Phase 3 - Right goal - DONE
Goal entity, goal-line detection, reset on score.

## Phase 4 - Kick + power - NEXT
Click-hold charge, release to shoot toward cursor, power meter.

## Phase 5 - Left goal + scoring
Second goal, score increments, HUD shows score.

## Phase 6 - Full team
11 players per side in formation, AI-driven off-ball.

## Phase 7 - Opponent AI
Mirrored formation, chase/hold behavior.

## Phase 8 - Player switching
Q cycles teammates, auto-switch on possession, active ring.

## Phase 9 - Pass vs shot
Aim-cone pass detection, shot fallback.

## Phase 10 - Goalkeepers
GK tracking, dive, catch, clear.

## Phase 11 - Match state machine
KICKOFF / PLAY / GOAL / HALFTIME / FULLTIME.

## Phase 12 - HUD and pause
Score, clock, half, power meter, pause menu.

## Phase 13 - Results
Final score, stats, play again.

## Phase 14 - Polish
Sounds, camera shake, ball trail.

## Phase 15 - Deploy
GitHub Actions to Pages.
