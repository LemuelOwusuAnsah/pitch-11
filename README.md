# Pitch 11

A browser-based 2D top-down football game. 11v11, real physics, working match state.

## Stack

- Astro 5
- TypeScript (strict)
- Phaser 3.90.0
- Matter Physics (via Phaser)
- Deployed to GitHub Pages

## Live

https://lemuelowusuansah.github.io/pitch-11/

## Development

    npm install
    npm run dev

Local dev runs at http://localhost:4321/pitch-11/

## Build

    npm run build
    npm run preview

Output goes to dist/
